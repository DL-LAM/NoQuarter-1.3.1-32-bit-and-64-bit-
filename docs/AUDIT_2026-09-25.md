# NQ 1.3.1 Source Audit — 2026-09-25

Every change from this audit is tagged in the code with `[NQ 1.3.1 - Audit <ID>]`.
To find a fix: search the source for its tag, e.g. `grep -rn "Audit C1" src/`.
Each tag has a comment right above the change explaining what was wrong and why the fix is safe.

## Earlier fixes included in the same commit (Linux 64-bit / LP64)

| Fix | Where |

## Verification done before commit
- Compiled qagame, cgame and ui for Linux x86_64 (GCC 11) and i386 (Zig/clang): 0 errors, no new warnings versus the previous code.
- Changed game files compiled for Windows x86 and x64 (MinGW via Zig) to exercise the WIN32 paths.
- Unit tests on the extracted functions: IPv4/IPv6 address parsing, UTF-8 name validation, ban IP/GUID matching incl. range bans, IP filter, mute time overflow, `va()` overflow detection, info-string boundaries, XP save files written by the old 32-bit, 64-bit and Windows builds.
